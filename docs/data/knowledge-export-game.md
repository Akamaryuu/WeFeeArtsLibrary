# WeFeeArtsLibrary ナレッジ案内（ゲーム用ゴーストライター向け知識）

## この文書の使い方（AI向けガイド）

これは木内和也（赤魔龍）の個人的な知識データベース「WeFeeArtsLibrary」の書き出しです。
リンク集が「どこにあるか」の情報なのに対し、ここには本人が検証・整理した「知識の中身」が入っています。

### サイト群の地図

- WeFeeArtsHub（全体のポータル）: https://akamaryuu.github.io/WeFeeArtsHub/
- 赤魔龍の工房（ブログ。ゲーム日誌・実験ログ）: https://akamaryuu.github.io/WeFeeArtsBlogs/
- WeFeeArtsLibrary（リンク集＋この知識データベース）: https://akamaryuu.github.io/WeFeeArtsLibrary/
- WeFeeArtsGameLibrary（所持ゲーム一覧、プレイ時間つき）: https://akamaryuu.github.io/WeFeeArtsGameLibrary/
- WeFeeArtsLaboratory（経歴サマリー、ゴーストライター用プロンプト）: https://akamaryuu.github.io/WeFeeArtsLaboratory/

### 知識の使い方

- この文書は「案内」です。カテゴリごとに分かれていて、各カテゴリのURLの中に、そのカテゴリの記事の「内容と記事URL」の一覧が入れ子で入っています
- 記事や回答を作るときは、まず関連するカテゴリのURLを開き、その中の目次から関連する記事を探し、記事URLの本文を根拠にすること
- 知識に書かれた数値・手順・条件は、本人が実機や実績で確認したものです。一般論や推測で上書きしないこと
- 知識にないことは、事実のように書かないこと。必要なら「知識にはない」と分かる形にすること
- 各記事の見出しにある「カテゴリ」「タグ」「日付」が手がかりです。内容が競合したら、日付の新しい方を優先すること
- 価格を書くときは円（¥）で書き、割引率は参考程度に留めること（本人の方針）

### この文書（ゲーム用）の担当範囲

- ゲームに関する知識だけを抜き出したものです
- 本人のプレイ環境（StarboundはMOD環境など）を前提にした検証情報が中心です。バニラ前提の一般情報と混同しないこと
- 所持ゲームやプレイ時間が必要なときは WeFeeArtsGameLibrary を参照すること
