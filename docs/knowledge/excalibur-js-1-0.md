## 要約

TypeScript製のオープンソース2Dゲームエンジン「Excalibur.js」が1.0正式リリース（発表は2026-11-11）。Webブラウザで動作する2DゲームをTypeScriptで制作でき、BSD 2-Clauseライセンスのもと無償で商用利用も可能。1.0では2Dライティング（光源と影の表現）に対応し、コマンドラインツール「ex」はMCPによるAIエージェント連携にも対応している。
